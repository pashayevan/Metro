# 🚇 Metro Simulation (Baku Metro Model)

Данный проект — симуляция движения поездов по линиям метро города Баку с помощью многопоточности на C++.

Поезда движутся по маршрутам, соблюдая блокировку станций (чтобы на одной станции не было двух поездов одновременно). Модель использует `std::mutex` и `std::thread` для синхронизации.

## 📜 Линии и маршруты

### 🔴 Красная линия
- **Поезд 1**: Бакмил → Ичери Шехер → Бакмил
- **Поезд 2**: Бакмил → Ичери Шехер → Улдуз → Азии Асланов → Бакмил

### 🟢 Зелёная линия
- **Поезд 3**: Бакмил → Дярнягюль → Бакмил
- **Поезд 4**: Бакмил → Дярнягюль → Улдуз → Азии Асланов → Дярнягюль

### 🟣 Фиолетовая линия
- **Поезд 5**: Ходжасан → 8 Ноябрь → Ходжасан (один круг, затем остановка)
- **Поезд 6**: Ходжасан → 8 Ноябрь → Ходжасан (один круг, затем остановка)

### 🟡 Жёлтая линия
- **Поезд 7**: Джафар Джабарлы → Хетаи (совершает 2 круга и останавливается)

## 🚀 Как запустить

### Для **Linux** :
```bash
git clone https://github.com/pashayevan/Metro.git
cmake -S . -B build
cd build
make
./Metro //запуск
```
- Исполняемый файл появляется в папке build

## ⚙️ Технические детали

- Используются `std::mutex` для блокировки станций (чтобы только 1 поезд был на станции одновременно).
- Каждая линия и поезд — это отдельный поток (`std::thread`).
- Поезда 5, 6 и 7 останавливаются после завершения заданного количества кругов.
- Safe printing реализован через `std::lock_guard` для `cout`.
